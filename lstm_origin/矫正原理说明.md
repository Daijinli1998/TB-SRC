# 步态关键点遮挡矫正原理说明

相关程序：`gen_fig45_46.py` / `train_v3.py` / `gen_compare_qualitative.py`

---

## 问题背景

双目相机在采集步态视频时，人体关节点（如脚踝、膝盖）会因为肢体遮挡、运动模糊等原因导致检测器输出错误坐标或低置信度结果。这些"坏帧"如果直接使用，会造成轨迹抖动甚至跳变，影响后续分析。

矫正的目标是：**用历史正常帧学到的运动规律，在遮挡发生时预测出合理的关节点位置，替代检测器的错误输出。**

---

## 第一步：遮挡帧检测

程序位置：`gen_fig45_46.py` — 遮挡帧检测部分

判断一帧是否为遮挡帧，满足以下任一条件即标记：

- **坐标突变**：当前帧与上一帧的归一化坐标差值超过 1.2，说明检测结果发生了不合理的跳变
- **低置信度**：检测器输出的置信度低于 0.55，说明该帧检测本身不可靠

标记后向前后各扩展 1 帧，避免遮挡边界帧被漏掉。

```
正常帧  正常帧  [遮挡帧]  正常帧  正常帧
              ↓ 扩展后
正常帧  [扩展] [遮挡帧] [扩展]  正常帧
```

---

## 第二步：构造伪标签

程序位置：`gen_fig45_46.py` — `make_pseudo_gt` 函数

遮挡帧没有可靠的真实坐标，无法直接监督训练。因此用以下方式构造训练目标：

1. 取所有正常帧的坐标，对遮挡帧位置做**线性插值**，得到平滑过渡的估计值
2. 对整条轨迹再做一次**均匀滤波（窗口=5帧）**，消除残余抖动

这个插值结果作为"伪GT"，告诉模型遮挡帧"应该在哪里"。

---

## 第三步：模型矫正

程序位置：`gen_fig45_46.py` — `MTFEM`、`OAGLSTMCell`、`FullModel` 类

模型输入过去 15 帧的坐标序列，输出当前帧的矫正坐标。由两个模块串联完成：

### MTFEM — 多尺度时频特征提取

用三个不同膨胀率（1 / 2 / 4）的卷积并行处理序列：

```
输入序列
  ├─ 膨胀卷积 d=1 → 捕捉短时运动（相邻帧变化）
  ├─ 膨胀卷积 d=2 → 捕捉中时运动（步态节律）
  └─ 膨胀卷积 d=4 → 捕捉长时运动（整体趋势）
        ↓ 拼接 + 线性投影 + 残差连接
     融合后的多尺度特征
```

目的是让模型同时感知不同时间粒度的运动规律，而不只看相邻几帧。

### OAG-LSTM — 遮挡感知门控 LSTM

在标准 LSTMCell 基础上，引入一个由**关键点置信度**控制的门控机制：

```
每个时间步：
  h_new, c = LSTMCell(x_t, h_old)
  g = Sigmoid( Linear(confidence_t) )   ← 置信度越低，g 越小
  h = g * h_new + (1 - g) * h_old       ← 遮挡时保留旧记忆
```

- 正常帧：置信度高 → g 接近 1 → 正常更新隐状态
- 遮挡帧：置信度低 → g 接近 0 → 保留上一步记忆，不让噪声污染隐状态

这样模型在遮挡发生时会"惯性滑行"，依靠历史运动规律推断当前位置，而不是被错误检测带偏。

---

## 第四步：加权损失训练

程序位置：`gen_fig45_46.py` — `WeightedLoss` 类

损失函数对遮挡帧赋予 3 倍权重，强迫模型把学习重心放在矫正遮挡帧上：

```
weight = 1.0（正常帧） 或 3.0（遮挡帧）
Loss = 0.7 × MSE × weight + 0.3 × MAE × weight
```

MSE 和 MAE 组合使用：MSE 对大误差敏感，MAE 对异常值鲁棒，两者互补。

---

## 整体流程图

```
原始关键点序列（含遮挡噪声）
        ↓
  遮挡帧检测（突变 + 低置信度）
        ↓
  构造伪标签（插值 + 平滑）
        ↓
  MTFEM 提取多尺度运动特征
        ↓
  OAG-LSTM 置信度门控时序建模
        ↓
  输出矫正后的关节点坐标
```
